# Imagens

## Logótipo (obrigatório para ficar igual ao Figma)

Coloca aqui o logótipo como **`logo.png`**:

1. No Figma, abre o ficheiro GameHall, seleciona a camada **`game_hall_white_text 2`** (no ecrã Home).
2. No painel direito, em *Export*, escolhe **PNG** e **3x** e exporta.
3. Renomeia o ficheiro para `logo.png` e coloca-o nesta pasta (`mobile/assets/images/logo.png`).

Enquanto o ficheiro não existir, a app mostra uma versão em texto ("GAME HALL") no lugar do logótipo.
